## ขั้นตอน
1. **ตั้งโปรเจกต์ + ถอดเสียง** (ElevenLabs Scribe · คีย์ `~/.elevenlabs/api_key` — ห้ามเปิดอ่าน/พิมพ์คีย์)

2. **ดูคลิป** — contact sheet ทุก 6 วิ · หาตำแหน่งหัวคนพูด → ตั้ง `FACE_CROP` **ตัดกว้าง** (เริ่มที่ `1000:1000:80:150`) ให้หัวกินแค่ ~ครึ่งวงกลม มีที่ว่างเหนือหัว · ดึงเฟรมทุกช่วง B-roll มาใส่หน้ากากวงกลมดูก่อนเรนเดอร์ — คนพูดขยับ/โน้มตัว ถ้าตัดแน่นหัวจะตกขอบวง (ผู้ใช้ติมาแล้ว)
3. **แบ่งระดับกราฟิก** จาก `work/transcript.txt` ตามตาราง "3 ระดับ": ประโยค Hook (3–4 วิแรก) · คำที่เป็น Super (~1 ครั้งต่อ 10 วิ) · จุด B-roll (1–3 ครั้ง) · หาเวลาด้วย `at('วลี')` (อ่านจาก scribe.json · Scribe สะกดอังกฤษเพี้ยนได้ เช่น "Gen C" "skill" ตัวเล็ก → เช็ค transcript ก่อน) · **บอกผู้ใช้เป็นรายการก่อนลงมือ**
   - ซับ: ก๊อป `renders/roughcut.srt` จาก base-rough-cut มาเป็น `work/subs.srt` (เวลาตรงกับ cut_1080 พอดี)
4. **หาภาพ** — Openverse API กรอง `license=cc0,pdm` · วัตถุชัด พื้นเรียบ · ลง `assets/raw/` · **จดที่มาใน `work/CREDITS.txt`** · ห้ามภาพคนดัง/โลโก้เด่น/ลายน้ำ
   ```bash
   python work/cutout.py assets/raw/x.jpg assets/cut/x.png --mode subject --bw   # ของ/คน: ลบพื้น (โมเดลในเครื่อง)
   python work/cutout.py assets/raw/x.png assets/cut/x.png --mode white --bw     # ภาพประกอบพื้นขาว
   python work/cutout.py assets/raw/x.jpg assets/cut/x.png --mode torn --tint navy --border 0   # ภาพฉาก: แผ่นขอบฉีก
   ```
   ทำ contact sheet ชิ้นที่ตัดแล้วดูทุกครั้ง · หาภาพไม่ได้ → ใช้แถบกระดาษ + เส้นชอล์กแทน
5. **เขียน `gen.py`** — แก้ "ตั้งค่าต่อคลิป" (TOTAL · FACE_CROP · SUBS) + เขียน `hook(...)` · `sup(...)` · `broll(...)` ของคลิปนี้แทนของต้นแบบ · ชิ้นที่ค้างนานใส่ `boil()`
6. **ตรวจ** `python gen.py && npx --yes hyperframes@0.8.147 lint` → 0 error
7. **ภาพนิ่ง** `npx --yes hyperframes@0.8.147 snapshot --at <เวลา,...> --no-end --describe false` ทุก Hook/Super/B-roll → ดู contact sheet (คำทับหน้า · Super ทับหัว · ชิ้นล้นการ์ด · วงกลมหน้าตกขอบ)
8. **เรนเดอร์ทั้งคลิป** (~4.5 นาทีต่อ 70 วิ · ห้ามถอด `--workers 1`):
   ```bash
   npx --yes hyperframes@0.8.147 render -q draft --workers 1 -o renders/<ชื่อ>-draft.mp4 > work/render_log.txt 2>&1
   ```
   (แบบ B-roll อย่างเดียววางทับคลิป Export → ใช้ `template/broll-only/` + `work/compose.py`)
9. **ตรวจไฟล์จริงก่อนบอกเสร็จ** — `ffprobe` (ความยาวเท่าคลิปเดิม · 1080×1920 · มีเสียง) · True Peak ≤ −1.0 · ดึงเฟรมจาก MP4: ก่อน/กลาง/หลังทุกช่วง B-roll · ก๊อปไป `~/Downloads/`

## กับดักที่เจอจริง
- **ไม้ยมก ๆ ต้องเว้นวรรคหน้าและหลังเสมอ** (มากๆ → มาก ๆ · จริงๆ → จริง ๆ) ทั้งในซับ, Super และ Text Hook (ผู้ใช้สั่ง) · สคริปต์แก้ในซับให้อัตโนมัติ ส่วนข้อความที่พิมพ์เองในฉากต้องเว้นเอง
- ม้วน B-roll ซ่อนช่วงที่ยังไม่ถึงด้วย `y:1920` (นอกจอ) · ชิ้นที่ตั้ง `y` ติดลบตอนเริ่ม (`drop`) ต้องเริ่ม `opacity:0` ไม่งั้นโผล่ในช่วงก่อนหน้า
- **ห้ามใช้ `clip-path` ทำขอบฉีก** (เยอะ ๆ จับภาพเป็นจอดำ) — ใช้ `edge()` SVG
- **ใช้ไฟล์ภาพซ้ำ ห้ามต่อท้าย `?n=`** (ตอนเรนเดอร์ไม่ขึ้น) — `piece()` ก๊อปเป็น `x-2.png` ให้เอง
- วงกลมหน้าใช้ไฟล์ `assets/cam{n}.mp4` แยกทุกช่วง (gen.py ตัดให้) — ห้ามใช้ไฟล์เดียวหลาย `<video>`
- `shake()` ค่าตายตัว ไม่ใช่ `+=` และเรียกหลังท่าเข้าจบ · ห้าม CSS `transform` บนชิ้นที่ GSAP ขยับ (มุมเอียงตั้งผ่าน `ROT`)
- ffmpeg `alimiter` ต้องใส่ `level=false` — ค่าเริ่มต้นดันเสียงขึ้นเต็มสเกลเอง (เคยได้ True Peak +0.8 dBTP) · compose.py ใส่ให้แล้ว
- Windows: ทุก `open()` ต้อง `encoding='utf-8'` · สคริปต์ที่พิมพ์ไทยต้อง `sys.stdout.reconfigure(encoding='utf-8')`
- ภาพนิ่ง `snapshot` ต้องใส่ `--describe false` เสมอ (ไม่งั้นส่งเฟรมงานลูกค้าไป Gemini)
