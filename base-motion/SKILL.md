### คลังภาพเปรียบ (หยิบให้ตรงความหมาย ไม่ใช้ซ้ำในคลิปเดียว)

## ⛔ ถามให้ครบก่อนเริ่ม (ทุกโหมด)
อย่าเพิ่งลงมือจนกว่าจะได้ 2 อย่างนี้ — ถามรวบทีเดียวได้ ไม่ต้องถามทีละข้อ

1. **ทำคลิปไหน** — ถ้าผู้ใช้ไม่ได้บอกชื่อโปรเจกต์/คลิปมา **ให้ถาม อย่าเดา** และอย่าหยิบซีเควนซ์ที่เปิดค้างอยู่ใน Premiere มาทำเอง (เขาอาจเปิดค้างไว้จากงานอื่น)
2. **มีไฟล์ประกอบไหม** — สคริปต์ · สไลด์ · เอกสารคอร์ส · โน้ตที่ใช้อัด อะไรก็ตามที่เกี่ยวกับคลิปนี้
   - **ทำไมต้องขอ:** ถอดเสียงพลาดคำเฉพาะเสมอ — ชื่อเครื่องมือ ชื่อคน ศัพท์เทคนิค ชื่อโมเดล/เฟรมเวิร์กของ BASE ถ้ามีต้นฉบับจะสะกดถูกและเรียกชื่อตรงกับที่สอนจริง
   - เอาไปใช้ตอน: แก้คำในสคริปต์ที่ถอดมา · ตั้งข้อความบนแผง · เลือกภาพเปรียบให้ตรงกับที่เนื้อหาสอนจริง
   - ไม่มีก็ทำได้ แต่ต้อง **บอกผู้ใช้ก่อนว่าคำเฉพาะอาจเพี้ยน** แล้วให้เขาตรวจตอนดู draft

## ขั้นตอน
1. **ตั้งโปรเจกต์ + ถอดเสียง** (ElevenLabs Scribe · ห้ามใช้ whisper เป็นหลัก — เคยหลุดช่วงยาวและหลอนท้ายคลิป)
   ```bash
   ~/.claude/skills/base-motion/scripts/new_project.sh <ชื่อ> "<คลิป.mp4>"
   ```
   คีย์อยู่ `~/.elevenlabs/api_key` (บัญชี ElevenLabs ของ BASE · ขึ้นต้น `sk_` — ไม่ใช่ Key ID) หรือ env `ELEVENLABS_API_KEY` · โปรเจกต์ไปอยู่ที่ `~/Developer/video-use/<ชื่อ>` (เปลี่ยนได้ด้วย env `BASE_MOTION_HOME`)
2. **ดูคลิป** — contact sheet ทุก 5 วิ: หาตำแหน่งหน้า (ตั้ง `#vbox top` ใน style.css) · มีการ์ดชื่อเรื่องทับหน้าตอนต้นไหม (ถ้ามี SHRINK ต้องหลังมันจาง)
3. **แบ่งซับเอง** → `work/captions.txt` บรรทัดละวลี 1–3 คำ (6–25 ตัวอักษร) · คำเน้นใส่ `*...*` · ข้อความต้องตรงกับที่ถอดทุกตัวอักษร (ไม่นับช่องว่าง) → `python3 work/align.py` ต้องขึ้นครบทุกบรรทัด (assert จะบอกบรรทัดที่ไม่ตรง)
   - ⚠️ Scribe ภาษาไทยคืนเวลาทีละ "ตัวอักษร/พยางค์" ไม่ใช่คำ — อย่าพยายามตัดคำอัตโนมัติ (เครื่องไม่มี pythainlp) แบ่งเองดีกว่าและแก้คำผิดได้ด้วย
4. **วางฉาก** — อ่าน transcript หาโครง (hook → ข้อ 1…N → สรุป) · เวลาเปิดฉากทุกจุดใช้ `at('วลีที่พูด')` ห้ามเดาตัวเลข · ออกแบบภาพเปรียบแต่ละข้อจากคลังด้านบน (หรือคิดใหม่ แต่ต้องอยู่ใน CI) แล้วบอกผู้ใช้สั้น ๆ ก่อนลงมือถ้าเป็นเรื่องใหม่
5. **เขียน `gen.py`** (โครงอยู่ใน template · ตัวอย่างครบใน `examples/pm-timeline/gen.py`) — ตัวช่วย `enter/leave/pop/grow/draw/stamp/fx/head` · ทุก `pop/draw` ที่มีความหมายควรมี `fx()` คู่
6. **ตรวจ** `npm run check` → ต้อง 0 error ยกเว้น overlap ที่ตั้งใจ (ตราประทับทับการ์ด — หรี่การ์ดเหลือ 0.3)
7. **ภาพนิ่ง** `npx hyperframes@0.8.147 snapshot --at <เวลา,...> --no-end --describe false` — ⚠️ ต้องใส่ `--describe false` ไม่งั้นมันส่งเฟรมไป Gemini เอง (งานลูกค้าหลุดออกไปได้) · ภาพนิ่ง**ไม่มีวิดีโอ** (ดำ) เป็นเรื่องปกติ
8. **เรนเดอร์** (ถ้า render จบใน ~3 วิแต่ไม่มีไฟล์ = ffmpeg มีปัญหา → อย่าใส่ `--quiet` · เก็บ log ไว้ดู · รัน `ffmpeg -encoders | grep libx26` ต้องเจอ):
   ```bash
   cd ~/Developer/video-use/<ชื่อ> && npx --yes hyperframes@0.8.147 render -q draft -o renders/<ชื่อ>-draft.mp4 > work/render_log.txt 2>&1
   ```
   ~8 นาทีต่อคลิป 2.5 นาที (draft) · ตัวจริงใช้ `-q delivery`
9. **ตรวจไฟล์จริง** — ffprobe (ความยาว/ขนาด/มีเสียง) + ดึงเฟรมจาก mp4 ทุกฉาก (ไม่ใช่ภาพนิ่ง) + ซูมดูฟอนต์ไทย · แล้วค่อยบอกผู้ใช้
10. **ให้ผู้ใช้ดู** — `open` ไฟล์ + ก๊อปไป `~/Downloads/` + (ถ้าจะปรับละเอียด) เปิด Studio `npx --yes hyperframes@0.8.147 preview --background` → http://localhost:3002
    - ⚠️ บอกผู้ใช้: **อย่าแก้ตรงใน Studio** — `gen.py` สร้าง index.html ใหม่ทับทุกครั้ง · ให้กดเลือกชิ้นแล้วบอก → ดึงด้วย `npx hyperframes@0.8.147 preview --selection --json`

## 🎞️ โหมด Premiere (overlay) — น้องตัดใน Premiere แล้วเอากราฟิกไปวางทับ
ใช้เมื่อผู้ใช้ตัดคลิปใน Premiere เอง (ตัดฉับ/จัดหน้าเสร็จแล้ว) แล้วอยากได้แค่ชั้นกราฟิก
1. ให้ผู้ใช้ export **ทั้ง sequence ที่ตัดแล้ว** เป็น H.264 (เลือก Match Sequence Settings · ความยาวตั้งแต่ 00:00 ถึงจบ) → ได้ไฟล์ที่เวลาตรงกับ timeline เป๊ะ
2. `new_project.sh <ชื่อ> "<ไฟล์ที่ export>" --overlay` → ใน gen.py จะตั้ง `OVERLAY = True`
   - ไม่มีวิดีโอคนพูดใน index.html · พื้นใส · ไม่ซูมสลับ · ไม่จางดำตอนจบ · เสียงใน MOV = **SFX ล้วน** (เสียงพูดตั้งเป็น 0 เพราะอยู่ใน Premiere แล้ว)
   - ขั้น 2–6 เหมือนเดิม (ถอดเสียง · แบ่งซับ · `at()` · ฉาก) · ตำแหน่งแผง/ซับยึดเฟรม 1080×1920 เดิม
3. เรนเดอร์เป็น MOV พื้นใส · **fps ต้องตรง sequence** (ดู `r_frame_rate` ที่ new_project พิมพ์ออกมา):
   ```bash
   npx --yes hyperframes@0.8.147 render --format mov -f <fps> --workers 1 -o renders/<ชื่อ>-overlay.mov > work/render_log.txt 2>&1
   ```
   ได้ ProRes 4444 + alpha (ไฟล์ใหญ่ ~6 MB/วินาที · คลิป 2.5 นาที ≈ 900 MB)
   - ⚠️ **`--workers 1` ห้ามถอด** — ถ้าไม่ใส่ คลิปยาว ๆ จะหลุดไปโหมด disk capture ที่เขียนทุกเฟรมเป็น PNG ลงดิสก์ก่อน (MOV มี alpha ต้องใช้ PNG บีบอัดไม่ได้) กินที่ **~250 MB ต่อวินาที** → คลิป 1:50 ขอ 27 GB แล้วเรนเดอร์ล้มกลางคัน · ใส่ `--workers 1` แล้วมันจะ encode ไปพร้อมจับภาพ ไม่แตะดิสก์เลย (ดู `encode (during capture)` ใน log)
   - เจอจริงเมื่อ 30 ต.ค. 2026: คลิป 1:22 ผ่าน แต่ 1:50 ล้ม — เพดานอยู่ระหว่างนั้น อย่าเสี่ยง ใส่ทุกครั้ง
4. **ตรวจก่อนส่ง:** `ffprobe` ต้องเห็น `pix_fmt=yuva444p12le` · ซ้อนบนพื้นสีทดสอบแล้วดึงเฟรมดูว่าใต้แผงใสจริง:
   `ffmpeg -f lavfi -i color=c=0x2e7d32:s=1080x1920:r=<fps>:d=<วินาที> -i renders/<ชื่อ>-overlay.mov -filter_complex '[0][1]overlay=format=auto' -ss <เวลา> -frames:v 1 work/check.png`
5. บอกผู้ใช้: ลาก MOV ไปวางบน **V2 ที่ 00:00** (เสียง SFX ไปลง A2 เอง) · ปรับตำแหน่ง/ขนาดหน้าคนพูดบน V1 ให้อยู่ใต้แผง (แผงสูง 800 px จากบน) · ถ้าตัดใน Premiere ใหม่ = ต้อง export + ทำ overlay ใหม่ (เวลาเลื่อน)
   - sequence ไม่ใช่ 1080×1920 → บอกผู้ใช้ก่อนทำ (เลย์เอาต์ออกแบบไว้แนวตั้งเท่านั้น)

## 🤖 โหมด Premiere อัตโนมัติ — เรียกทีเดียว ไม่ต้องแตะ Premiere เลย
ใช้เมื่อผู้ใช้บอกชื่อโปรเจกต์ (`/base-motion AI PR`) หรือสั่งลอย ๆ ว่าทำคลิปที่เปิดอยู่ใน Premiere
เหมือนโหมด overlay ทุกอย่าง ต่างแค่ **ไม่ต้องให้ผู้ใช้ export เองและไม่ต้องลากไฟล์เอง**

**ต้องมีก่อน:** Premiere เปิดอยู่ + แผง **AI Story Cutter** เปิดค้างไว้ (`Window › Extensions`)
แผงคือตัวที่คอยรับใบงาน ถ้าปิดแผง = สะพานขาด สคริปต์จะรอจนครบเวลาแล้วบอกเองว่าให้ไปเปิดแผง

1. **ชื่อซีเควนซ์** — ผู้ใช้บอกชื่อมา → ใช้ชื่อนั้น · **ไม่บอก → ถามก่อนเสมอ** (ดูหัวข้อ "ถามให้ครบก่อนเริ่ม")
   - ส่ง `""` = ใช้ซีเควนซ์ที่เปิดบนไทม์ไลน์ — ใช้ได้**ต่อเมื่อผู้ใช้ยืนยันแล้วว่าตัวที่เปิดอยู่คือตัวที่ต้องการ** ห้ามเดาเอง
   - โปรเจกต์เดียวมักมีหลายซีเควนซ์ (เช่น `0310`, `Nested Sequence 01`) ถามให้ชัดว่าอันไหน
2. **สั่ง Premiere export ไฟล์อ้างอิง** (แทนขั้น 1 ของโหมด overlay):
   ```bash
   python3 ~/.claude/skills/base-motion/scripts/premiere_bridge.py export "<ซีเควนซ์>" <โปรเจกต์>/assets/talk.mp4
   ```
   - **เซฟโปรเจกต์ของผู้ใช้ให้เอง** เพราะ AME เรนเดอร์จากไฟล์บนดิสก์ · ไม่ปิดโปรเจกต์ที่เปิดอยู่
   - ส่งเข้า Media Encoder แล้วรอจนไฟล์เขียนเสร็จจริงให้เอง (เช็คว่าขนาดหยุดโต) ไม่ต้องนั่งเดาเวลา
   - ไฟล์นี้มีซับจาก Premiere เบิร์นติดมาด้วย **ไม่เป็นไร** เพราะใช้เป็นตัวอ้างอิงเสียง/เวลาเท่านั้น ไม่ใช่ไฟล์ส่งงาน
3. ทำ overlay ตามโหมดด้านบน (ข้อ 2–4) โดยใช้ไฟล์ที่ได้มาเป็น `assets/talk.mp4`
4. **วางกลับเข้า timeline** (แทนขั้น 5 ของโหมด overlay):
   ```bash
   python3 ~/.claude/skills/base-motion/scripts/premiere_bridge.py insert renders/<ชื่อ>-overlay.mov "<ซีเควนซ์>" --video 1 --audio 1 --at 0
   ```
   - ถ้า **V2 มีคลิปอยู่แล้วมันจะปฏิเสธ ไม่ทับให้** (กันรันซ้ำแล้วทับงานคนอื่น) · จะทับต้องเติม `--replace` → **ถามผู้ใช้ก่อนเติมทุกครั้ง**
5. **จัดหน้าคนพูดบน V1 ให้พ้นแผง** (แผงสูง 800 px):
   ```bash
   python3 ~/.claude/skills/base-motion/scripts/premiere_bridge.py frame "<ซีเควนซ์>" --video 0 --dy 550
   ```
   - **บวกจากค่าปัจจุบัน ไม่ได้เซ็ตทับ** → เรียกซ้ำเพื่อจูนทีละนิดได้ (`--dy -50`) และไม่ลบเฟรมที่ช่างตัดจัดไว้เอง
   - **วิธีหาค่า:** พื้นที่ใต้แผงคือ 800 → 1920 กลางอยู่ที่ **1360** · ดึงเฟรมมาดูว่าหัวอยู่ px ไหน แล้วขยับให้เข้าใกล้ 1360
   - ค่าที่ใช้จริงมาแล้ว: **450–550 px** (ขึ้นกับว่าช่างตัดจัดเฟรมต้นทางไว้ยังไง)
6. บอกผู้ใช้ว่าเสร็จแล้ว · ถ้าตัดใน Premiere ใหม่ = ต้องรันใหม่ทั้งรอบ (เวลาเลื่อน)
7. **ถ้าผู้ใช้ขอไฟล์ส่งงาน** — export ซีเควนซ์ที่มี overlay แล้วออกมาเป็นไฟล์เดียว:
   ```bash
   python3 ~/.claude/skills/base-motion/scripts/premiere_bridge.py export "<ซีเควนซ์>" <ที่เก็บ>/<ชื่อ>.mp4 --no-captions
   ```
   - ⚠️ **ไฟล์ส่งงานต้องใส่ `--no-captions` เสมอ** ไม่งั้นซับจาก Premiere จะถูกเบิร์นติดภาพลบไม่ได้ แล้วซ้อนกับ CC เป็นสองชั้น (ไฟล์อ้างอิงขั้นกลางไม่ต้องใส่ก็ได้ ไม่กระทบ)
   - ตรวจก่อนบอกเสร็จ: `ffprobe` ความยาว/ขนาด + ดึงเฟรมจริงมาดู + เช็คเสียงด้วย `ffmpeg -af loudnorm=print_format=summary` — **True Peak ควร ≤ −1.0 dBTP** (เคยได้ +0.1 แล้วเสี่ยงเสียงแตกตอนแพลตฟอร์มบีบอัดซ้ำ → ลดเสียง SFX บน A2 ลง 2–3 dB)

## กับดัก lint ของ HyperFrames (เจอแล้วจริง)
- ห้าม tween `left/top` → ใช้ `x/y` (กระตุกตอนเรนเดอร์) · `width` ได้
- ห้ามมี CSS `transform` บน element ที่ GSAP ขยับ → ตั้งค่าเริ่มด้วย `tl.set(...,0)` หรือใช้ `top:`
- ตัวเลขโปร่ง (`color: transparent`) โดน `text_not_painted` → ใช้สีพื้นจาง `#e6e1d9` + stroke `#cdc7bd`
- ป้ายที่ทับหัวข้อ/ตัวเลขใหญ่ → ย้ายไปขอบล่างของกล่อง
- ฟอนต์ต้องมี `@font-face` ชี้ไฟล์ใน `fonts/` (ฟอนต์ระบบแพ็กไม่ได้)
- อย่าใช้ `re.sub` backreference ใน f-string ของ HTML (ได้ `\1` ดิบ) → ใช้ `.replace()`
