## ฟังก์ชันใน gen.py
| ฟังก์ชัน | ทำอะไร |
|---|---|
| `hook(t_end, [(t, ข้อความ, คลาส, y)])` | คลาส `hk-lbl` (ป้ายแดง) `hk-s` (ไทยเล็ก) `hk-xl` (Poppins 150) `hk-em` (ไทยแดง 140) |
| `sup(t0, t1, rows, pops)` | rows = `[(html, y)]` · pops = `[(id, เวลาเด้ง)]` · ซ่อนซับช่วงนี้ให้เอง |
| `pill(id, txt, on, fl)` | แคปซูล (on = พื้นแดง · fl = มีไอคอนไฟ) |
| `chip(id, ttl, lbl, hot)` | การ์ดหัวข้อ + ป้ายเล็ก (hot = ขอบแดง) |
| `LV = [...]` | การ์ดระดับล่างจอ: (วลีเริ่ม, วลีจบ, n, ชื่อ, คำอธิบาย) + `track(n)` แถบ n/4 |
| `broll(t0, t1, body)` | จอเต็ม + วงกลมหน้า (`assets/cam{n}.mp4` ตัดให้เอง) · ซ่อนซับให้เอง |
| `hd(lbl, ttl)` | หัวจอ B-roll |
| `.card.st` + `.rail/.rail-f/.dot` | แถวเส้นทาง Shift Stage (B1) |
| `.chat-hd` + `.msg/.bub/.tag` | แชทภารกิจ (B2) |
| `gauge(id, x, y, w, val0, big)` | เกจ Hype ครึ่งวง · `fill(id,t,val)` · `count(id,t,v0,v1,d)` ตัวเลขวิ่ง |
| `flame(w, col)` | ไอคอนไฟ (SVG วาดเอง ไม่ใช้อีโมจิ) |
| ท่า: `pop` `slide` `bump` `out` | เด้งเข้า · เลื่อนเข้า · เด้งเน้น · หายขึ้น |

## จับคู่เนื้อหา → ชิ้นส่วนแอป (ไอเดียจาก C2673)
- มีลำดับขั้น / ระดับ / ด่าน → **เส้นทาง Shift Stage** (แถวการ์ดล่าง→บน + เส้นแดงไต่)
- ตัวอย่างบทพูดหัวหน้า–ลูกทีม → **แชทภารกิจ** (ข้อความไล่ระดับ · อันเก่าจางลง · แถบแดงใต้หัวแชทเต็มขึ้น)
- พลัง / ความแรง / คะแนน → **เกจ Hype** + ตัวเลขวิ่ง
- เทียบ 2 ฝั่ง → **การ์ดคู่** (ฝั่งแพ้จาง 40% · ฝั่งชนะขอบทอง)
- ชื่อแนวคิดยาวที่อธิบายนาน → **การ์ดระดับล่างจอ** ค้างทั้งช่วง (ไม่ต้องตัดเป็น B-roll)

## id ห้ามซ้ำรูปแบบที่ระบบใช้
`g{n}` (ช่วง B-roll) · `cam{n}` · `sb{n}` (ซับ) · `hw{n}` (Hook) · `lv{n}` — เกจชื่อ `g1` เคยชนกับช่วง B-roll แล้วหายทั้งอัน ใช้ `gg1` `gp` แทน
