## 🚫 กฎห้ามพลาด (ผู้ใช้จับได้เองทุกข้อ — อย่าให้เกิดซ้ำ)
**ตัดต่อ**
1. **เทคสุดท้ายถูกเสมอ** — คำ/ประโยคซ้ำติดกัน (ถาม ถาม · เปิดเว็บ ×3 · เราควรจะบอกเขาไปชัด ×2) เก็บครั้งหลัง
2. **หาซ้ำที่ไม่ติดกันด้วย** — พูดสะดุด ("ข้อมูลที่มันเป็นข้อมูลที่…") · พูดทวน ("…ไปเก็บไว้ใน Memory พอมันไปเก็บไว้ใน Memory") · แก้คำ ("ช่วยเขียน Report… ช่วยวางแผนทริป") → `repeats.py` แล้วอ่าน NEAR ทีละจุด
3. **เนื้อหาต้องไม่ทำให้งง** — อ่าน transcript ไฟล์ตัดแล้วทั้งเรื่อง: พูด "ห้าแหล่ง" แล้วต่อ "สองแหล่งเราคุยกันไปแล้ว" = ตัดหรือถามผู้ใช้
4. **Scribe รวมคำซ้ำเป็นคำเดียว + วางเวลาคลาด** → หาขอบคำจากเสียง (`energy.py`) · ตัดที่ช่วงเงียบจริงเท่านั้น
5. **เศษคำหลุดตรงจุดตัด** ("ส…" ของสอง 40 ms) → `joincheck.py` หลังตัดทุกครั้ง
6. **เดดแอร์** — `deadair.py` (−32 dB ≥ 0.15 วิ เหลือ 0.12) · ห้ามใช้ช่องว่างเวลาตัวอักษร Scribe (เคยตัดคำจริงทิ้ง) · ไฟล์ส่งต้องไม่มีเงียบ ≥ 0.3 วิ
7. **ต่อกันต้องสมูท** — rough.py เฟดเสียง 12 ms ทุกชิ้น + ปัดจุดตัดเข้าขอบเฟรมไฟล์ดิบ (ไม่งั้นภาพ/เสียงเหลื่อมทุกจุดตัด)
8. **ตัดใหม่ = เสียงใหม่** — gen.py ผูก `voice.wav` กับ talk.mp4 แล้ว แต่โปรเจกต์เก่าต้องลบ `gfx/assets/voice.wav` เอง (C2675 Draft 3 เสียงไม่ตรงปาก 0.6–1.3 วิ)

**ซับ**
9. **ตัดบรรทัดตามวลี/ไวยากรณ์ไทย** ห้ามตัดกลางคำ ("ความ | แม่น" ✗) → ร่างด้วย `autocaps.py` (pythainlp + จังหวะหยุด) แล้ว**อ่านแก้ทุกบรรทัดที่ขึ้นจริง**ด้วย `capfix.py` (rough.py แบ่งตามจำนวนตัวอักษร ใช้ไม่ได้)
10. **ห้ามย่อขนาด** — บรรทัด > 30 ตัว (นับแบบ `len()`) ขึ้นบรรทัดใหม่ · gen.py assert ให้แล้ว
11. **ไม่ขึ้นคำ เนาะ เนอะ นะ ป่ะ อ่ะ** — `caps2srt.py` ลบให้ (นะครับ → ครับ)
12. **Super / การ์ดล่างจอ / B-roll / ปก ขึ้น = ไม่มีซับเลย** — แยกคำที่เป็น Super เป็นบรรทัดของตัวเอง ("คือที่มาของคำว่า" | "Hallucination") · lvcard/LV ใส่ HIDE_SUBS ให้แล้ว

13. **ปก = ชื่อคลิปจากสคริปต์ (คอลัมน์ ชื่อคลิป / ช็อต) ไม่มี MICRO LEARNING** — คำหลักหน้า ":" แบ่ง ขาว/แดง ตัวใหญ่ · ส่วนหลัง ":" 1–2 บรรทัดขาว · เด้งทีละบรรทัดใน ~1 วิ ค้างจนจบปก (ต้นแบบ `C2675_ปก.png`)

**CI (ผู้ใช้สั่ง 19 พ.ย. 2026: "เวลาตรวจ เช็ค CI ด้วยทุกครั้ง")**
14. **ฟอนต์ไทยต้องเป็น IBM Plex Sans Thai ทุกตัว · อังกฤษ/ตัวเลข Poppins** — ทุก font stack ที่มี Poppins ต้องมี `'Plex Thai'` ต่อท้าย
    (ปกคลิป 10–12 คำไทยตัวใหญ่ "อาการ" "สั่งรูปแบบ" อยู่ใน `.hk-xl` ที่เป็น Poppins อย่างเดียว → ตกไปฟอนต์ระบบ ผิด CI · ผมดูแค่ภาพย่อไม่ได้ซูม ผู้ใช้จับได้)
    · ตรวจอัตโนมัติ `python3 $K/scripts/cicheck.py <โปรเจกต์>` = ฟอนต์ + สี (ดำ/ขาว/แดงเท่านั้น) + ห้ามไล่สี + ห้าม glow · buildclip/renderclip หยุดถ้าไม่ผ่าน · check_final ข้อ 8
    · **แล้วดูด้วยตาทุกครั้ง:** เปิด `renders/<ชื่อ>_ปก_ซูม.png` (renderclip ทำให้) ซูมปกทุกคลิป + เฟรมที่มีป้าย/ชิปภาษาไทย — สคริปต์จับได้แค่ CSS ไม่เห็นภาพจริง

**ก่อนบอก "เสร็จ"** → `check_final.py <ไฟล์ส่ง>` ผ่านข้อ 1–6 + 8 (CI) + อ่าน ADJ/NEAR + ดึงเฟรมจาก MP4 ทุกฉาก (ภาพนิ่ง snapshot ไม่นับ) + **ซูมปกเช็คฟอนต์ CI ทีละคลิป**
