> สถานะ 10 พ.ย. 2026: **ผ่านผู้ใช้แล้ว** ต้นแบบ = คลิป Gen Z vs Gen Y 16 วิแรก (`template/gen.py` · ประวัติแก้ 7 รอบใน `F:\AI\test-animation-skills\blueprint\NOTES.md`)
> ที่มา: บรีฟ Editor "โครงสร้างคลิปสั้น + สไตล์ Blueprint" (Hook → Body · Subtitle / Super / Animation) + ภาพอ้างอิงแพ็ก Envato "Hand Drawings" (ดูแนวเท่านั้น ไม่ได้ใช้ไฟล์ของแพ็ก)

## ⛔ ถามให้ครบก่อนเริ่ม
1. **คลิปไหน** (ไฟล์ที่ตัดเสร็จ) + **มีโฟลเดอร์ base-rough-cut ของคลิปนี้ไหม** (มี → ได้ไฟล์ดิบ 4K + ซับ · ไม่มี → ถามหาไฟล์ดิบ ไม่งั้นต้องลด CLOSE เหลือ 1.25)
2. คลิปมี **ซับ/ปกเบิร์นมาแล้วไหม** — ดูเฟรมเอง (ถ้ามี ซับเราจะซ้อนสองชั้น)
3. ประโยค Hook — ไม่ให้มา = เสนอจากคำพูดในคลิป แล้วบอกว่าเป็นคำที่ตั้งเอง

## ขั้นตอน
1. **ตั้งโปรเจกต์ + ภาพความละเอียดสูง + ถอดเสียง** (ElevenLabs Scribe · คีย์ `~/.elevenlabs/api_key` — ห้ามเปิดอ่าน/พิมพ์คีย์)
   ```bash
   python ~/.claude/skills/base-motion-blueprint/scripts/new_blueprint.py <ชื่อ> "<คลิป.mp4>" --rough "<โฟลเดอร์ base-rough-cut>"
   ```
   สคริปต์ตัดช่วงเดียวกันจากไฟล์ดิบ (อ่าน `work/source.json` + `work/keep.json` · แปลง HLG→SDR · ครอปกลาง) → `assets/talk_hi.mp4` 1620×2880 · ซับ `renders/roughcut.srt` → `work/subs.srt`
2. **เช็กภาพ** — ดึงเฟรม `talk.mp4` เทียบ `talk_hi.mp4` 2–3 จุด: มุมและจังหวะต้องตรงกัน (เคยเจอไฟล์ดิบเก็บแบบหมุน 90° → ffmpeg หมุนให้เอง) · หาตำแหน่งหน้า → ตั้ง `FACE`
3. **วางจังหวะ** จาก `work/transcript.txt` · หาเวลาด้วย `at('วลี')` (ห้ามเดาตัวเลข · Scribe สะกดอังกฤษเพี้ยน เช่น "Gen C" → เช็ก transcript) · **บอกผู้ใช้เป็นรายการก่อนลงมือ**: Hook · ฉากวาด 1–2 ฉาก (ภาพเปรียบไม่ซ้ำ) · Super ~1 ครั้ง/10 วิ · จุดตัดขนาดภาพ (ประโยคใหม่ = เปลี่ยนขนาด · คำแรง = ใกล้ · คำตอบ = กว้าง)
4. **เขียน `gen.py`** — แก้ "ตั้งค่าต่อคลิป" (TOTAL จากข้อความท้ายขั้น 1) แล้วเขียน A/B แทนตัวอย่าง Gen Z · วงล้อมต้องวัดตำแหน่งคำจริง (ฟอนต์ลายมือกว้างไม่เท่ากัน)
5. **ตรวจ** `python gen.py && npx --yes hyperframes@0.8.147 lint` → 0 error · ซับเกิน 30 ตัว สคริปต์เตือน → แบ่งใหม่
6. **ภาพนิ่ง** `npx --yes hyperframes@0.8.147 snapshot --at <เวลา,...> --no-end --describe false` (ต้องมี `--describe false` เสมอ) ทุก Hook/Super/ฉากวาด → ดู: วงล้อมตรงคำ · ตัวหนังสือไม่ล้นจอ · เส้นใต้ไม่โดนตัวหนังสือทับ · ซับไม่ทับปาก
7. **เรนเดอร์** `npx --yes hyperframes@0.8.147 render -q high --workers 1 --frames-cache-dir off -o renders/<ชื่อ>.mp4 > work/render_log.txt 2>&1`
8. **ตรวจไฟล์จริงก่อนบอกเสร็จ** — `ffprobe` (ความยาว · 1080×1920 · มีเสียง) · peak ≤ −1 dBFS · ดึงเฟรมจาก MP4 ทุก Hook/Super/ฉากวาด + **ครอปช็อตใกล้ดูความคม** + **ซูมตัวหนังสือไทยทุกคำ** (สระ/วรรณยุกต์ต้องไม่ขาด) · เขียน `NOTES.md`

## กับดักที่เจอจริง
- ภาพ `talk_hi.mp4` ต้องเป็น SDR bt709 — ถ้ายังติดแท็ก HLG/bt2020 hyperframes จะเรนเดอร์แบบ HDR (แตกเฟรม 16 บิต ~6 GB) · สคริปต์เช็กให้แล้ว (เคยพลาดเพราะไฟล์ดิบแบบหมุนมี side data)
- ซับจาก base-rough-cut: คำลงท้ายมักติดคำถัดไป ("อันนี้ป่ะบน") → template ตัดทุกตำแหน่ง · บรรทัดยาว > 28 ตัว (นับเฉพาะตัวที่กินที่ ไม่นับสระบน/ล่าง วรรณยุกต์) แบ่งเป็น 2 ซับต่อกันเองที่ช่องว่าง · ไม่มีช่องว่าง → สคริปต์เตือน ให้แบ่งเองใน .srt
- **ไดรฟ์ C: เต็ม** → render ไม่เริ่ม (ใส่ `--frames-cache-dir off` ไม่ให้ค้างแคช) ("Low disk space") · ตัวกินที่ = `%TEMP%\hyperframes-extract-cache-*` (ลบได้ แต่ถามผู้ใช้ก่อน) · ย้าย temp ไป F: ไม่ได้ (F: ทำ symlink ไม่ได้ → `EISDIR`)
- ฟิลเตอร์พู่กัน: ริ้วหมึกแห้งถี่/กว้างกว่าค่าใน template → ตัวไทยขาด อ่านไม่ออก · ขุยรอบขอบ (rim speckle) → ผู้ใช้บอก "ไม่เหมือนพู่กัน"
- mask ท่าเขียน (`clipPath inset`) ต้องเผื่อซ้ายขวา 20% ไม่งั้นตัวเอียง/ขอบพู่กันโดนตัด
- เส้น SVG ที่ยังไม่วาด ต้องซ่อน (`opacity:0` จนถึงเวลาวาด) ไม่งั้นปลายเส้นมนค้างเป็นจุด
- `fromTo` ของวงกระเพื่อม/ของที่ขึ้นทีหลัง ใส่ `immediateRender:false` ไม่งั้นโผล่ตั้งแต่เฟรมแรก
- ฟอนต์ลายมือทำหนาด้วย dilate มากไป (≥3) ช่องในตัวอักษรตัน — template ใช้ 2.2 + ริ้วตัดเนื้อ

## ข้อจำกัดที่รู้แล้ว
1. ไม่มีไฟล์ดิบ = ช็อตใกล้ได้แค่ 1.25× (ภาพ 1080 ขยายมากกว่านี้แตก)
2. ฉากวาดใน template มีแบบเดียว (เปรียบเทียบ 2 ฝั่ง) — flowchart / แปลน / กราฟ / บันได ต้องเขียน `pen()` เองตามบรีฟหน้า 17
3. ทดสอบกับคลิปเดียว (Gen Z · 16 วิแรก) · ยังไม่ได้ลองคลิปเต็มความยาว
4. Sriracha เป็นลายมือเส้นเท่ากัน พู่กันมาจากฟิลเตอร์ — ไม่เหมือนพู่กันจริง 100%
