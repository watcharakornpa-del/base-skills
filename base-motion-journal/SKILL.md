## ⛔ ถามให้ครบก่อนเริ่ม
1. **คลิปไหน** — ไฟล์ที่ตัดเสร็จแล้ว หรือช่วงไหนบนไทม์ไลน์ (ห้ามเดา)
2. **ไฟล์ประกอบ** — ซับ `.srt` ของทีม · สคริปต์ · สไลด์ (ใช้สะกดคำเฉพาะให้ถูก)
3. **ธีม** navy หรือ ember (ถ้ายังไม่เคยเลือก) · **ชื่อปก** 2 บรรทัด (ถ้าไม่ให้ เสนอจากประโยคเปิด แล้วบอกว่าเป็นคำที่ตั้งเอง)

## ขั้นตอน
1. **ตั้งโปรเจกต์ + ถอดเสียง**
   ```bash
   ~/.claude/skills/base-motion-journal/scripts/new_journal.sh <ชื่อ> "<คลิป.mp4>" "<ซับทีม.srt>"
   ```
2. **ตัดกรอบหน้าสำหรับวงกลม** — ไฟล์แยก `assets/cam.mp4` (ห้ามใช้ `talk.mp4` ซ้ำใน `<video>` ตัวที่สอง → lint `duplicate_media_discovery_risk` วงกลมว่าง) · ดึงเฟรมดูก่อนว่าหัวอยู่ตรงไหน แล้วตั้ง crop ให้เห็นเต็มหัว+ไหล่ (คลิป 4 ใช้ `900:900:90:150`):
   ```bash
   ffmpeg -v error -i assets/talk.mp4 -t <TOTAL> -an -vf "crop=900:900:90:150,scale=450:450" -c:v libx264 -crf 18 -pix_fmt yuv420p -y assets/cam.mp4
   ```
3. **ความยาว** — หาเวลาคำสุดท้าย (`work/scribe.json`) ถ้าท้ายคลิปเป็นจอดำให้ตัด → ตั้ง `TOTAL` ใน `gen.py`
4. **ซับ** — มี `.srt` ของทีม: `python3 work/srt_align.py` (เทียบข้อความทีมกับเสียงจริงด้วย difflib → `work/subs.json`) · ต้องเจอครบทุกบรรทัด · คำที่ทีมสะกดไทยแต่ถอดได้อังกฤษ เพิ่มใน `SAME` · **SRT ของทีมจับเวลาจากคลิปดิบและมีคำผิด** เทียบกับเสียงจริงทุกครั้ง แก้ใน `TYPO` ของ gen.py แล้วบอกผู้ใช้
5. **วางฉาก B-roll** — อ่าน transcript หาประโยคหลัก 4–6 จุด · เวลาเปิด/ปิดทุกฉากใช้ `at('วลีที่พูด')` ห้ามเดาตัวเลข · ภาพแต่ละฉาก**ต้องคนละแบบ**และสื่อความเดียว · บอกผู้ใช้สั้น ๆ ก่อนลงมือว่าจะวาดอะไรตรงไหน
6. **เขียน `gen.py`** — แก้ชื่อปก (`#cv-t1`, `#cv-t2`) + แทนฉาก `broll(1..N)` ของคลิป 4 ด้วยของคลิปนี้ · ตัวช่วย: `ink()` เส้น+ghost · `draw()` วาดตามเวลา · `mk()`/`swipe()` แรเงา · `splat()` กระแทก · `shake()` สั่น · `pop()` เด้ง · `fx()` เสียง
7. **ตรวจ** `python3 gen.py && npm run check` → 0 error
8. **เรนเดอร์** (ห้ามถอด `--workers 1`):
   ```bash
   THEME=navy python3 gen.py && npx --yes hyperframes@0.8.147 render -q draft --workers 1 -o renders/<ชื่อ>-draft.mp4 > work/render_log.txt 2>&1
   ```
9. **ตรวจไฟล์จริงก่อนบอกเสร็จ** — `ffprobe` (ความยาว/1080×1920/มีเสียง) · True Peak ≤ −1.0 · ดึงเฟรมจาก MP4 ทุกฉาก (ปก · ซับ · ทุกการ์ด · วงกลมมีหน้า) + ซูมฟอนต์ไทย
10. ก๊อปไป `~/Downloads/` + `open` · เขียน `NOTES.md` ในโปรเจกต์

## กับดักที่เจอจริง
- **ฟิลเตอร์ rough ทำเส้นนอน/เส้นตั้งหายทั้งเส้น** (กรอบเส้นสูง 0 → พื้นที่ฟิลเตอร์ 0) → ต้อง `filterUnits="userSpaceOnUse"` + x/y/width/height ใหญ่ (template ตั้งไว้แล้ว อย่าลบ)
- `fromTo` ต้องใส่ `opacity` ทั้งฝั่ง from และ to ไม่งั้น lint `gsap_cold_seek_hidden_fromto_missing_reveal` ของหายตอนเรนเดอร์
- ห้าม CSS `transform` บน element ที่ GSAP ขยับ · `.stage` (scale 1.1) ไม่ถูก GSAP แตะ — ห้ามขยายเกิน 1.1 ภาพกว้างจะล้นการ์ด
- เส้นที่ไม่ต้องมีเส้นซ้ำ (เส้นช่วย) ใช้ `draw(..., ghost=False)`
- ไฟล์ที่ export จาก Premiere มีซับเบิร์นมาด้วยไหม ดูก่อน — ถ้ามี ซับของเราจะซ้อนสองชั้น
- ภาพนิ่ง `snapshot` ต้องใส่ `--describe false` เสมอ (ไม่งั้นส่งเฟรมไป Gemini)
